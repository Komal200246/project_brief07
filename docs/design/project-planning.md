# Project Summary: Job Portal System

## 1. Selected Project Name
* **Project Title**: Job Portal System[cite: 2]
* **Project ID**: T7[cite: 2]

## 2. Problem Statement
* **Problem**: Traditional recruitment relies on fragmented communication channels, manual candidate tracking, and inefficient information management[cite: 2].
* **Affected Parties**: Employers struggling to organize applicants and job seekers unable to monitor their application status[cite: 2].
* **Solution**: A centralized web platform that unifies job postings, application workflows, and recruitment progress tracking in real time[cite: 2].

## 3. Project Objective
To develop a secure, scalable, and user-friendly MERN stack recruitment platform that streamlines hiring for employers and simplifies application submission for job seekers[cite: 2].

## 4. Stakeholders
* **Administrator**: System manager overseeing user accounts, listings, and global settings[cite: 2].
* **Employer / Recruiter**: Business user creating job postings, reviewing candidates, and updating application status[cite: 2].
* **Job Seeker**: Applicant creating profile details, searching jobs, and submitting applications[cite: 2].

## 5. Project Scope
* **Included Scope**: User authentication & authorization (JWT), company profile management, job posting CRUD, applicant profiles, application status tracking, and recruitment reporting dashboards[cite: 2].
* **Excluded Scope**: AI resume screening, live video interviews, email server integration, third-party job board syndication, and mobile app development[cite: 2].

## 6. Functional Requirements
* **Authentication**: Registration, login, JWT token verification, role-based access control (RBAC)[cite: 2].
* **Company & Job Management**: Add/update company details; create, edit, delete, filter, and search job listings[cite: 2].
* **Applicant & Application Management**: Maintain applicant profile/resume info; apply to jobs; view application history and status updates[cite: 2].
* **Recruitment Workflow**: Review applicants, update recruitment status (Pending, Shortlisted, Rejected, Hired), and view hiring metrics[cite: 2].

## 7. Non-Functional Requirements
* **Performance**: Fast job search filtering and responsive REST API response times[cite: 2].
* **Security**: Password hashing (bcrypt), JWT authorization, protected routes, and input validation[cite: 2].
* **Usability & Maintainability**: Responsive design, intuitive navigation, modular React components, and structured backend architecture[cite: 2].
