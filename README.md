# Home Hub – Property Rental and Real Estate Platform

## Project Overview

Home Hub is a property rental and real estate platform designed to help users easily search, explore, compare, and find suitable properties. The platform also allows property owners to add, publish, and manage their property listings.

The main goal of Home Hub is to provide a simple, user-friendly, and convenient platform for both property seekers and property owners.

---

## Project Objective

The objective of Home Hub is to:

- Make property searching simple and convenient.
- Help users find properties based on their requirements.
- Provide useful search and filter options.
- Allow users to view complete property details.
- Enable users to save and compare properties.
- Provide direct communication between property seekers and owners.
- Allow property owners to add and manage property listings.
- Provide a better and organized property rental experience.

---

## Target Users

### 1. Property Seekers

Property seekers can:

- Register and log in.
- Search for properties.
- Apply filters.
- View property listings.
- View property details.
- Compare properties.
- Save favourite properties.
- Contact property owners.
- Schedule property visits.

### 2. Property Owners

Property owners can:

- Register and log in.
- Access the owner dashboard.
- Add new properties.
- Enter property details.
- Upload property photos.
- Submit and publish listings.
- Receive enquiries from users.
- Respond to users.
- Manage their property listings.

## Installation and Setup

### Step 1 – Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2 – Open the Project

Open the Home Hub project folder in Visual Studio Code.

### Step 3 – Install Frontend Dependencies

Open the frontend/client folder:

```bash
cd client
```

Install dependencies:

```bash
npm install
```

### Step 4 – Start the Frontend

```bash
npm start
```

---

## Backend Setup

Open a new terminal and move to the server folder:

```bash
cd server
```

Install backend dependencies:

```bash
npm install
```

Start the backend server:

```bash
npm start
```

---

## Environment Variables

Create a `.env` file inside the server folder and add the required configuration.

Example:

```text
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

Do not upload passwords, API keys, or other private credentials to GitHub.
